# Adhoc

One-off scripts, experiments, and exploratory utilities that are not yet part of stable workflows.

These scripts may:
- Be temporary experiments
- Be one-off comparisons
- Be test utilities for debugging
- Not have full documentation or error handling

## Scripts

| Script | Purpose |
|--------|---------|
| `social_sources_expansion_research.py` | Research additional subreddits/queries/instances |
| `test_reddit_direct.py` | Unit test for Reddit adapter |
| `test_social_sources.py` | Integration test for social sources |

## Note

Scripts here are not guaranteed to be maintained or stable. They serve
as scratch space for experimentation. If a script proves useful, consider
promoting it to `measurements/` or `repo_health/`.
