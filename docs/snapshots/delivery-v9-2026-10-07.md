## BF2 on a real run

```
runtime.browserFallbackDemand =
  {attempts: 851, refused: 617, servedWithHtml: 226, servedEmpty: 8,
   servedEmptyEnvironment: 4, servedEmptyPage: 4}
```

The split is what the change was for. `servedEmpty: 8` used to be one number standing for "the
browser could not launch" and "the page rendered with no jobs in it"; with 617 of 851 attempts
refused, the population was unreadable. Four of each is now a reportable finding.

**And the run found a defect in the change itself:** 95 rows carried
`browserFallbackRecommended: true`, and **0** carried the run's cause. The stamp read the flag
off the report row, but the flag is written on the row's *detail* during the fetch and hoisted
to the top level later, by report normalization — so the stamp landed on nothing. That is the
false green the work was meant to remove, reproduced inside it. Fixed to read either level, with
two tests, one of which quotes the v9 numbers.

## The 17 greenhouse `fetched_empty` boards are the game filter, not dormancy

v9 and v8 both report 17 greenhouse boards as `fetched_empty` — asked, time spent, nothing kept.
That reads like a failure, so it was re-probed control-first (`2k` answered **122 jobs** before
any board was asked, so the API was healthy and not rate-limited as it was during v8):

| board | rows served | game roles |
|---|---:|---:|
| taketwo | 32 | 0 |
| applovin | 43 | 0 |
| adjustjobs | 14 | 0 |
| growe | 11 | 0 |
| kambi | 8 | 0 |
| fastspring | 3 | 0 |
| keensoftwarehouseas, 2kvegas | 2 each | 0 |
| unknownworlds | 2 | 0 |
| crystaldynamics, dots, inzoistudio, pmstudios, pubgmadison, tripwireinteractive, kano | 1 each | 0 |
| **firaxis** | 1 | **1** — "Join Our Talent Community" |

Sixteen of seventeen serve nothing this product wants: Take-Two's board is corporate roles,
and AppLovin, Kambi, Adjust, FastSpring and Growe are not game studios. Firaxis's one survivor
is a talent-community mailing list, not an opening.

So `fetched_empty` on these boards means **a board that is not a game board**, which is worth
recording because the state name reads like a board that failed. The filter was shipped in
0.3.012; these boards were registered before it, and the 0.3.012/0.3.013 registrations were
role-gated while this earlier population was not.

**They stay registered.** The product's rule is that every game opening is worth having, so a
board that might hire game roles is worth watching even while it serves none — `fetched_empty`
is the honest state for it, and `justplay-gmbh` and `scape` in the same set already collect.
